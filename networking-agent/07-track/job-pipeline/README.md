# job-pipeline — Consulting-category accepted leads

Copies of accepted consulting-bucket files. Different cadence: slow + warm, never asks for a referral on first contact. Goal is converting acceptances into referrals to MBB recruiting / coffee chats over months, not weeks.

Cadence:
- T+0 days: wait
- T+7 days: warm acknowledgement, share a relevant resource or thoughtful question, no ask
- T+30 days: second touch, pattern-match on their recent activity
- T+90 days: optional — surface specific interest if context fits (e.g. they posted about a hiring push)
