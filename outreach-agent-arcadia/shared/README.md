# shared/

Cross-stage references that more than one stage needs but don't fit
neatly into `_config/` or `skills/`.

Currently empty. Add files here only when a real cross-stage need
emerges. Examples that might land here later:

- `arcadia-feature-map.md` - quick reference of Arcadia features mapped
  to common creator pain points (used by enrichment for the pitch
  justification AND by personalization for hook generation)
- `competitor-intel.md` - what we know about Whop, Heartbeat, Geneva,
  Skool - used to handle "we already use X" objections in personalization
  and reply routing
- `case-studies.md` - once we have closed-won customers, their stories
  become reusable assets for hook library, personalization, and bumps

Don't pre-create empty files. Add when the second stage that needs the
content starts asking for it.
