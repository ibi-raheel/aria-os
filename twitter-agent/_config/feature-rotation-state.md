# Feature rotation state

Tracks which features have been posted and when. Prep task reads this to determine today's feature and updates it after posting.

```yaml
last_posted:
  world-spawn: 2026-05-10       # Day 1
  studio-overview: null
  the-kiln: null
  the-stage: null
  members-roll: null
  billing-ledger: null

last_cycle_day_posted: 1         # Day 1 = cycle day 1 (The World)
```
